# Чек-лист релиза

Отмечается в описании PR в `main`. Пункт, который нельзя проверить, помечается «не проверено» с
причиной — он не считается выполненным.

## 1. Beta-версия перед Stable

- [ ] Все обязательные проверки CI зелёные на последнем коммите проверяемой ветки (не «пропущено» по ошибке пути).
- [ ] `npm run check` и `python -m pytest` локально без падений.
- [ ] Стенд Supabase (`cloud.yml`) зелёный: миграции с нуля и повторно, RLS, security-тесты.
- [ ] Beta установлена рядом со Stable на macOS и Windows; обе запускаются одновременно; у Beta метка «Beta».
- [ ] Данные Stable не изменились (число лидов, настройки, вход) после работы с Beta.
- [ ] Сценарии Scenario Runner (этап 2+) — все PASS; SKIPPED перечислены с причинами.
- [ ] Обновление Stable с предыдущей версии: данные на месте, «Что нового» показан один раз.
- [ ] Нет открытых критических ошибок.

## 2. Stable

- [ ] `release-check.cjs --tag vX.Y.Z` пройден (идёт в `release.yml`).
- [ ] Debug Menu и генераторы данных отсутствуют в Stable (release-check: модуль `debug` только под `beta`).
- [ ] Миграции сервера применены сначала на проекте Beta, затем — с разрешения Maksim — на рабочем; сверка числа строк.
- [ ] Установщик Windows: установка, обновление поверх с сохранением данных, удаление (`check.ps1`).
- [ ] Образ macOS: подпись, архитектуры arm64 и x86_64, идентификатор `local.leadgenerator.app`, ссылки `leadgenerator`.
- [ ] Release smoke: запуск собранного приложения, вход, поиск, экспорт (вручную на обеих ОС).
- [ ] Заметки релиза `.github/release-notes/vX.Y.Z.md`.
- [ ] Подтверждение публикации в окружении `production` — Maksim.
