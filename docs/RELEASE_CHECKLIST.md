# Чек-лист релиза

Отмечается в описании PR в `main`. Пункт, который нельзя проверить, помечается «не проверено» с
причиной — он не считается выполненным.

Канал один (ADR-034): Beta и предварительных версий нет, поэтому всё проверяется до слияния в `main` и на стенде.

## 1. Перед релизом

- [ ] Все обязательные проверки CI зелёные на последнем коммите `main` (не «пропущено» по ошибке пути).
- [ ] `npm run check` и `python -m pytest` локально без падений.
- [ ] Стенд Supabase (`cloud.yml`) зелёный: миграции с нуля и повторно, RLS, security-тесты.
- [ ] Обновление с предыдущей версии: данные на месте, «Что нового» показан один раз.
- [ ] Нет открытых критических ошибок.

## 2. Релиз

- [ ] `release-check.cjs --tag vX.Y.Z` пройден (идёт в `release.yml`).
- [ ] Миграции сервера проверены на стенде и — с разрешения Maksim — применены на рабочем проекте; сверка
      read-only запросом.
- [ ] Установщик Windows: установка, обновление поверх с сохранением данных, удаление (`check.ps1`).
- [ ] Образ macOS: подпись, архитектуры arm64 и x86_64, идентификатор `local.leadgenerator.app`, ссылки `leadgenerator`.
- [ ] Release smoke: запуск собранного приложения, вход, поиск, экспорт (вручную на обеих ОС).
- [ ] Заметки релиза `.github/release-notes/vX.Y.Z.md` (желательно; без файла GitHub соберёт заметки сам).
- [ ] Подтверждение публикации в окружении `production` — Maksim.
