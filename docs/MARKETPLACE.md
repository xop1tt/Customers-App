# Коннекторы: модерация и первый модератор

Каталог коннекторов (ADR-083) и модерация на сервере (ADR-095). Пользовательское описание — wiki «Коннекторы и Ai».

## Путь коннектора

1. Компания разработчика подаёт заявку (`market_company_save`). Сервер проверяет данные теми же правилами, что и
   приложение (`private.market_company_problem`): полное название, страна, регистрационный номер, сайт https,
   политика конфиденциальности на сайте, рабочая почта на домене сайта (не gmail, mail.ru и подобные).
2. Модератор подтверждает или отклоняет компанию с причиной (`market_company_review`).
3. Проверенная компания подаёт коннектор (`market_submit`). Сервер проверяет манифест (`private.market_manifest`) и
   карточку (`private.market_checks`); замечание уровня fail отклоняет подачу целиком, отчёт хранится в
   `market_versions.checks`.
4. Модератор видит очередь (`market_review_queue`): описание, контакты, компанию, права и каждый адрес манифеста,
   автопроверку при подаче и сейчас, прошлые решения. Одобрение (`market_review`) возможно только без замечаний fail
   и у проверенной компании; отказ — только с причиной.
5. Одобренная версия становится live, коннектор получает `status = 'listed'` и появляется в каталоге
   (`market_catalog`) и доступен для установки (`market_install`). Неодобренные, отклонённые и снятые в каталог не
   попадают и не устанавливаются.
6. Каждое решение пишется в журнал `private.market_audit` (`market_audit_log`), разработчик получает уведомление
   (`market_notices`, отметка прочтения — `market_notices_read`). Снять с каталога и вернуть — `market_suspend`,
   список снятых — `market_suspended`.

## Модераторы

Модератор — учётная запись Customers из `private.platform_admins`. Пока там пусто, модерировать некому: блок
«Модерация» в разделе «На проверке» никому не виден.

### Назначить первого модератора (один раз, владелец проекта)

После применения миграции `20261121140000_market_moderation.sql` откройте **Supabase → SQL Editor** рабочего проекта
и выполните, подставив почту своей учётной записи Customers (она должна быть подтверждена):

```sql
insert into private.platform_admins (user_id)
select id from auth.users where lower(email) = lower('ВАША_ПОЧТА') and email_confirmed_at is not null
on conflict (user_id) do nothing
returning user_id;
```

Запрос должен вернуть одну строку. Пустой результат — почта не найдена или не подтверждена. Затем перезапустите окно
«Коннекторы» в приложении: в разделе «На проверке» появится блок «Модерация».

Остальных модераторов добавляют из приложения: «На проверке» → «Модерация» → «Модераторы».

### Проверка (read-only)

```sql
select count(*) as moderators from private.platform_admins;
select to_regprocedure('public.market_audit_log(integer, bigint)') is not null as moderation_ready;
```
