# Этап 1. Аудит источников и бесплатных интеграций (05.11.2026)

## Как проверялось

- Официальные документы, тарифные страницы, robots.txt — через веб-поиск и чтение страниц.
- **Прямой доступ к сайтам из среды разработки был закрыт сетевой политикой** (прокси отвечал 403
  на любой внешний хост). Поэтому ни один источник не проверен «вживую» отсюда. Парсеры написаны
  под документированные форматы (RSS 2.0, VK API, Overpass JSON, разметка t.me/s) и покрыты тестами
  на синтетических фикстурах. **Первая живая проверка — за владельцем** (workflow Diagnose / ручной
  запуск в dry-run, Python-версия с поиском в Actions удалена в 2026-11, ADR-051).
- Серверы GitHub Actions находятся за пределами РФ. Часть российских сайтов может ограничивать
  зарубежные IP — это риск, который проявится только при первом запуске.

## Источники заказов

| Источник | Решение | Способ | Обоснование |
|---|---|---|---|
| FL.ru | ✅ реализован | Публичная RSS `https://www.fl.ru/rss/all.xml` | Официальная лента. В момент проверки сайт отдавал страницу «технические работы» — работоспособность ленты подтвердит первый запуск |
| Telegram-каналы | ✅ реализован | Веб-превью `https://t.me/s/<канал>` | Bot API **не умеет** читать чужие каналы (только где бот — админ). Превью есть только у публичных каналов. Список каналов задаёт владелец |
| VK, открытые сообщества | ✅ реализован, выключен | Официальный VK API `wall.get` + бесплатный сервисный ключ | `newsfeed.search` (поиск по всем постам) сервисным ключом недоступен — читаем стены выбранных сообществ |
| Kwork | ❌ не подключён | — | Список проектов подгружается JavaScript'ом, публичного API/RSS нет. Внутренний XHR недокументирован: сломается без предупреждения, и это обход интерфейса площадки |
| Freelance.ru | ❌ не подключён | — | Публичную RSS не нашёл (типовые адреса не существуют). Если найдёте ленту — добавьте её в `feeds` RSS-источника, кода писать не нужно |
| Habr Freelance | ❌ не подключён | — | `robots.txt`: `Disallow: /` — владелец явно запрещает автоматический сбор |
| Workspace.ru | ❌ не подключён | — | Нет API/RSS. Писать HTML-парсер без возможности увидеть реальную разметку = выдавать заглушку за интеграцию |
| Яндекс Услуги | ❌ не подключён | — | Нет API, динамический интерфейс с антибот-защитой |
| Weblancer | ❌ не подключён | — | RSS не подтверждена; robots.txt закрывает поиск и фильтры |

## Организации

| Источник | Решение | Обоснование |
|---|---|---|
| Яндекс Карты (API Поиска по организациям) | ❌ | Бесплатные условия (yandex.ru/dev/commercial/doc): API только для проектов в открытом доступе, **запрещено сохранять данные**, результаты нужно показывать на карте. База лидов противоречит условиям; коммерческая лицензия платная |
| 2ГИС (Places API) | ❌ | Бесплатно — только демо-ключ, создаётся один раз и действует месяц (docs.2gis.com). Это пробный период |
| **OpenStreetMap / Overpass API** | ✅ замена | Бесплатно, данные под ODbL — хранить можно с указанием «© участники OpenStreetMap». Минус: в РФ полнота ниже, чем у Яндекса/2ГИС, телефоны и сайты указаны не у всех |
| Проверка сайтов организаций | ✅ | Один GET на сайт: доступность, HTTPS, meta viewport, год в копирайте, признаки онлайн-записи. Это проверяемые факты |

## Поисковые системы

| Сервис | Решение | Обоснование |
|---|---|---|
| Яндекс | ❌ | Официальный доступ — Yandex Search API в Yandex Cloud, тарифицируется. Бесплатного постоянного лимита не нашёл (детально тариф в этой сессии не проверял). Парсинг выдачи нарушает правила и упирается в капчу |
| Google / Bing | ❌ | Не проверял в этой сессии; по моим данным Bing Search API закрыт, а Google Custom Search JSON API закрыт для новых клиентов — требует перепроверки, поэтому не подключал |

## Внешние сервисы анализа (использовались Python-версией, удалена в 2026-11, ADR-051)

Итог: бесплатно и надёжно работают Notion API, Telegram Bot API, Hunter (50 кредитов/мес) и
webhook в Make / n8n. Apollo и Snov.io не подключены: у Snov.io API на бесплатном тарифе выдаётся только
по запросу через демо, у Apollo доступ к API на бесплатном тарифе подтвердить не удалось. Ни один из
сервисов не даёт бесплатного AI-анализа через API на постоянной основе.
