# Импорт клиентов из CSV и Excel (пакет B1)

Мастер «Импорт» на странице любой коллекции CRM переносит компании, контакты и сделки из таблицы.
Кнопка видна тем, у кого есть право `records.create`.

## Шаги мастера

1. **Файл.** CSV/TXT или Excel `.xlsx` до 10 МБ и 20 000 строк. Первая строка — заголовки. Здесь же список
   последних импортов с кнопкой «Отменить».
2. **Сопоставление.** Для каждой колонки ядро предлагает поле по заголовку (`suggest`): «Компания», «ИНН», «Сайт»,
   «Телефон», «Почта», «ФИО», «Должность», «Сделка», «Сумма», «Валюта», «Этап», «Комментарий» и английские
   аналоги. Одно поле — одна колонка. Режим дубликатов: связать (по умолчанию), пропустить, создать заново.
3. **Проверка.** Счётчики «Новых / Уже есть / Пропуск / Ошибок» и первые 100 строк, ошибки сверху. В базу
   ничего не пишется.
4. **Результат.** Сколько создано и связано, строки с ошибками, этапы, которых нет в воронке. Кнопка «Отменить
   импорт».

## Правила

| Что | Как |
|---|---|
| Кодировка CSV | BOM UTF-8/UTF-16, затем UTF-8, иначе Windows-1251 |
| Разделитель | `;`, `,` или табуляция — по первой строке; кавычки по RFC 4180 |
| Excel | первый лист книги, общие строки, числа без лишних `.0`; формулы — сохранённое значение |
| Компания | нужно название; телефоны и почты накапливаются списком |
| Контакт | «ФИО» делится на имя и фамилию; телефон и почта без имени и с компанией в строке относятся к компании; без имени и без компании — ошибка строки |
| Сделка | название или «Сделка: <компания или контакт>»; сумма понимает `180 000,50`, `1 500 ₽`; валюта RUB/USD/EUR/… по коду или знаку; этап по имени, неизвестный — первый этап с предупреждением |
| Заметка | колонки «Заметка» собираются в одну заметку к компании, а без компании — к контакту |
| Почта | неверный адрес — предупреждение, строка загружается без него |
| Дубликаты | ключи «Похоже на» (ИНН, телефон, почта, домен сайта, название) по базе и по строкам выше в том же файле |

Записи создаются тем же `WorkspaceStore::save`, что и ручной ввод: проверяются права, ведётся история,
в облачном Workspace изменения уходят на сервер обычной синхронизацией. Ошибка одной строки не прерывает импорт.

## Отмена

Каждый импорт с созданными записями получает номер в локальной таблице `import_batches` базы Workspace на
устройстве (файл, время, итог, список созданных записей). Отмена мягко удаляет созданные записи в порядке
заметки → связи сделок с контактами → сделки → контакты → компании; они попадают в корзину и восстанавливаются
оттуда. Записи, найденные как дубликаты, не трогаются. Повторная отмена ничего не делает. Список импортов
не синхронизируется: отменить импорт можно на том устройстве, где он сделан.
