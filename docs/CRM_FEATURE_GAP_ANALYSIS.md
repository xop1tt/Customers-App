# Сравнительный функциональный аудит CRM (Feature Gap Analysis)

Дата: 2026-11-11. Режим: **только чтение** — код, стили, тесты и миграции не менялись. Парный документ: [UI_UX_AUDIT_REPORT.md](UI_UX_AUDIT_REPORT.md).
Ограничения проекта (CLAUDE.md §2, ADR-033/034/039/053): только macOS и Windows, без Web и мобильных приложений, без AI-функций, без enterprise-доменов, этап 3 — только приложение, без миграций и Supabase. Эти ограничения учтены в рекомендациях: функция, которая им противоречит, получает пометку «вне курса», а не «пробел».

## 0. Как читать документ

**Статус функции в Customers** (определяется по коду и `docs/`, не по ощущению):

| Статус | Смысл |
|---|---|
| полностью | есть экран/действие, покрыто тестами |
| частично | есть, но без части ожидаемого (указано без чего) |
| технически без UI | данные/право/команда есть, экрана нет |
| только базовая | минимальная версия |
| отсутствует | в `desktop/src` и `docs/` не найдено |
| невозможно проверить | не удалось подтвердить без реального окружения |

**Легенда матрицы конкурентов:** ● полная · ◐ частичная · ○ отсутствует · $ ограничено тарифами · ? не удалось подтвердить в этой сессии.

**Честная оговорка о конкурентах.** В этой сессии страницы читались выборочно: **подтверждены** Salesforce (Flow, отчёты по сделкам, история полей, КП), HubSpot (последовательности, workflows, шаблоны писем), Pipedrive (таблица возможностей тарифов, автоматизации, e-mail sync, каталог продуктов, журнал аудита, webhooks/API). По Bitrix24, Dynamics 365, Zoho CRM, Freshsales в §2 отчёта UX/UI читались страницы **про интерфейс** (канбан, карточка записи, аудит у Dynamics), но не страницы по каждой функции этой матрицы — там стоит «?». Значение «?» не означает «функции нет»; оно означает «я не проверил и не утверждаю». Тарифные ограничения проверялись только там, где страница их прямо называет.

## 8. Преимущества Customers

1. **Встроенный поиск клиентов** как источник базы — у PD аналог только платная надстройка LeadBooster (подтверждено).
2. **Офлайн-first и локальные данные**, шифрование локальной базы (SQLCipher) — подтверждено кодом; сравнение с конкурентами по офлайн-режиму **не проверялось**.
3. **Бесплатность** без деления функций по тарифам (подтверждено решениями проекта).
4. **Простые и прозрачные права** и «отмена» для опасных массовых операций.
5. **Единое десктоп-приложение** без браузера.

## 12. Итоговое заключение

Customers уже закрывает базовый цикл малого бизнеса: найти клиента → завести → вести сделку → не забыть следующий шаг → увидеть воронку и прогноз, — бесплатно и офлайн. Самый заметный разрыв с подтверждёнными конкурентами (Salesforce, HubSpot, Pipedrive) — **автоматизации и последовательности касаний**, а следом **товары и коммерческие предложения**; оба блока по решению проекта ждут отдельного PR с базой и в этап 3 не входят. В рамках этапа 3 самые ценные шаги — честная корзина (G-01), полноценная таблица CRM (G-03) и защита от дублей при создании (G-16); журнал действий (G-02) стоит делать, если данные уже доступны без новых столбцов. Уникальное конкурентное преимущество — поиск клиентов внутри CRM; его естественное развитие (карта, оценка) выгоднее копирования корпоративных функций. Большая часть enterprise-функций (SSO, публичный API, мобильные клиенты) противоречит курсу и не рекомендуется.

Ничего из перечисленного не реализовано и не начато: жду решения Maksim.
