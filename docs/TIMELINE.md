# Лента клиента (пакет B3)

Вкладка «Лента» карточки компании, контакта, лида CRM и сделки показывает всю историю по времени, новые сверху.

| Вид | Откуда | Фильтр |
|---|---|---|
| Заметка, комментарий | `notes`, `comments` записи | Заметки |
| Звонок, письмо, встреча и другие события | `activities` (время — `occurred_at`) | События |
| Поставлена задача / задача выполнена | `tasks` (`created_at`, `completed_at`) | Задачи |
| Этап сделки «было → стало» | история этапов сделки | Этапы |
| Запись создана | `created_at` записи | Этапы |

* У **компании** в ленту добавляются записи её сделок и контактов (до 20, по свежести изменений) с подписью
  «Сделка: …» / «Контакт: …»; щелчок по тексту открывает источник.
* Удалённые заметки, комментарии, события и задачи не показываются.
* Добавить заметку, комментарий или событие можно здесь же; задачи — на вкладке «Задачи».
* Отдельная вкладка «Этапы» у сделки убрана: смены этапов — в ленте (фильтр «Этапы»).

Код: `desktop/src/lib/timeline.ts` (`buildTimeline`, `filterTimeline`, `relatedForTimeline`), `app/crm/CrmCard.tsx`
(`Feed`). Тесты: `lib/timeline.test.ts`, `app/crm/timeline.test.tsx`.
