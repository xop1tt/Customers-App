# Быстрый поиск Ctrl/Cmd+K (пакет G5)

Решение — ADR-058. Только интерфейс, без новых команд ядра.

## Как открыть

* ⌘K на macOS, Ctrl+K на Windows (`App.tsx`, обработчик клавиш; ⇧⌘K не перехватывается — это пункт меню
  «Отметить все как просмотренные»).
* Кнопка-лупа в верхней панели (видна, когда есть Workspace).
* Окно — `app/QuickSearch.tsx`, логика — `lib/quick.ts`, состояние — `quickOpen` в `state/store.ts`.

## Что ищет

* Компании, контакты, сделки, задачи и лиды CRM: по `ws_list` с `search` (те же поля, что и строка поиска
  списков; без учёта регистра, в том числе русских букв), до 5 записей каждого типа, запросы параллельно, с
  задержкой 150 мс после ввода.
* Действия: «Новая компания / контакт / сделка / задача / лид» (только с правом `records.create`) и «Перейти:
  Сегодня / Календарь / Сделки / Отчёты». При вводе текста остаются действия, в названии которых он есть.
* Подписи: телефон и почта у компаний и контактов, компания или человек у лида, срок у задачи.

## Управление

* ↑ ↓ — выбор (по кругу), Enter — открыть, Esc — закрыть, мышь — наведение и щелчок.
* Запись открывается в карточке справа. Если сейчас открыт не модуль CRM, сначала открывается подходящий раздел:
  сделки — «Сделки», задачи — «Календарь», остальное — «Сегодня» (`goToRecord` в `state/store.ts`).
* Права не обходятся: ядро отдаёт только то, что видно роли, кнопки создания скрыты без права.
