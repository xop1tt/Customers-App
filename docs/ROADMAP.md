# Дорожная карта

Утверждена Maksim 2026-11-11 по итогам read-only аудита. Решения — DECISIONS.md 033–043.

Правила:
* одновременно в работе один пакет; следующий начинается, когда предыдущий слит в `main` с зелёным CI;
* новые функции вне этого списка не начинаются (ADR-036);
* шаги, которые меняют бизнес-логику, удаляют данные, трогают рабочий проект Supabase или публикуют релиз, выполняются только после отдельного «да» Maksim в треде задачи.

## Порядок пакетов

| # | Пакет | Цель | Готово, когда |
|---|---|---|---|
| 1 | **D1** CLAUDE.md и документация | инструкции для Claude Code, актуальные статусы и решения | `CLAUDE.md`, ARCHITECTURE §1, DECISIONS 033–040, этот файл |
| 2 | **Удаление Beta** | один канал Stable, меньше кода и проверок | нет `beta.yml`, признака `beta`, модуля `debug`, Debug Menu; все тесты Stable зелёные; данные пользователей Stable не затронуты |
| 3 | **A1** Резервные копии | данные не теряются | резервная копия включает базы CRM `workspaces/*.db` и восстанавливается; ежедневный зашифрованный дамп облака; ежемесячная проверка восстановления в CI |
| 4 | **A2** Учёт миграций | схема управляема | история миграций рабочего проекта совпадает с `supabase/migrations`; новые миграции применяются одной командой после проверки на стенде |
| 5 | **A3** Фоновое обслуживание | база не растёт без предела | регулярный запуск очистки (удалённые записи, журналы доставок, старые уведомления) |
| 6 | **A4** Исправления безопасности | закрыть находки аудита | SSRF в webhooks, данные после удаления аккаунта, автопроверка security definer функций, константа репозитория обновлений, лишние файлы в Git, защита от утёкших паролей |
| 7 | **C1** Макеты | выбрать навигацию и экраны CRM | 2–3 варианта прототипа, выбор Maksim |
| 8 | **B1** Импорт CSV/Excel | перенос клиентов из таблиц и других CRM | мастер: сопоставление колонок, предпросмотр, дубликаты, отмена импорта |
| 9 | **B2** Канбан сделок и «Сегодня» | главный рабочий экран продаж | доска этапов с перетаскиванием и суммами; задачи на сегодня и просроченные |
| 10 | **C2** Новая навигация | CRM в центре, поиск клиентов — модуль | реализован вариант из C1 |
| 11 | **B3** Таймлайн клиента | вся история в одной ленте | задачи, события, заметки, комментарии, смены этапов в карточке |
| 12 | **D2** Упрощение | меньше наследия | удалён Python-генератор (проверка каталога OSM перенесена в Rust), мёртвый код найден инструментами и удалён |
| 13 | **Этап 2** Отчёты и автоматизации | руководитель видит воронку, рутина уходит | отчёты воронки, конверсии, план/факт; правила «если → то» через общую очередь событий |

## Не делаем

* Web-версию и мобильные приложения (ADR-033).
* Beta, Preview, ранний доступ (ADR-034).
* AI-функции и enterprise-домены (ADR-039).
* Платную инфраструктуру и подпись сборок (ADR-035, ADR-037) — до отдельного решения.
