# Частые проблемы

## Приложение для macOS

| Симптом | Что делать |
|---|---|
| «Не удаётся открыть, разработчик не установлен» | Правый клик по приложению → **Открыть** → **Открыть**. Сборка подписана ad-hoc, macOS спрашивает один раз |
| Поиск ничего не находит | Проверьте, что источники включены и в них есть каналы, ленты или города. Посмотрите «Журнал поиска» и ошибки источника в правой панели. Пустой список ключевых слов пропускает всё, слишком узкий отсекает лишнее |
| Telegram-канал: «нет публичного превью» | У канала выключено веб-превью или неверное имя. Проверьте `https://t.me/s/<имя>` в браузере |
| VK: ошибка 5 | Неверный сервисный ключ. Ошибки 15/30 — сообщество закрытое |
| Источник падает с 403 или таймаутом | Площадка временно недоступна или ограничивает запросы. Приложение повторит попытку на следующем интервале |
| Забыл пароль локальной учётной записи | Восстановить нельзя: пароль не хранится. Создайте новую учётную запись и восстановите данные из резервной копии |
| Облачный вход: «нет связи с сервером» | Проверьте интернет. Если неделю не было запросов, бесплатный проект Supabase засыпает: возобновите его в панели Supabase |
| Не приходит письмо с кодом | Проверьте «Спам». Письма ограничены лимитами, подождите и запросите код снова. Подробности: [docs/cloud.md](https://github.com/xop1tt/Customers-App/blob/main/docs/cloud.md) |
| После обновления macOS просит пароль Связки ключей для «LeadGenerator» | Приложение хранит в Связке ключей ключ VK, запомненный вход и токены облака. macOS спрашивает, когда у приложения сменилась подпись. Введите пароль и нажмите **«Разрешать всегда»**. Если релизы подписаны постоянным сертификатом ([как настроить](Разработка-и-сборка#подпись-релизов)), запрос будет один раз, а не после каждого обновления |
| Не ставится обновление | Если папка с приложением недоступна для записи, откроется dmg: перетащите приложение на «Программы» с заменой |
| Приложение вылетело или зависло | При следующем запуске оно предложит отправить отчёт. Или «Справка» → «Сообщить о проблеме…» ([подробно](Обновления-и-отчёты-о-сбоях)) |
| Много мусора или мало заявок | Подстройте ключевые слова источников и исключения, посмотрите причины оценки в панели лида ([подробно](Оценка-и-фильтры)) |

## Поиск в GitHub Actions

| Симптом | Что делать |
|---|---|
| Ничего не приходит в Telegram | Проверьте `LEADGEN_MODE=live` и запустите Diagnose с `ping`. Убедитесь, что вы написали боту хотя бы одно сообщение |
| `Notion: missing_properties` | В базе не хватает полей. Создайте поля вручную или командой `notion-init` |
| Notion 401/404 | Интеграция не подключена к странице/базе (**⋯ → Connections**) |
| Источник `fl_ru` падает с 403/таймаутом | Площадка не пускает IP GitHub. Временно выключите источник, обойти это нельзя |
| `telegram_channels: нет публичного превью` | У канала выключено веб-превью или неверное имя |
| `VK API 5` | Неверный сервисный ключ. `VK API 15/30` — сообщество закрытое |
| «Не удалось расшифровать кэш» | Сменился `STATE_ENCRYPTION_KEY`. Состояние восстановится из Notion |
| Расписание перестало работать | В 1.0.2+ оно выключено намеренно. Если вы его включали: прошло 60 дней без коммитов, нажмите **Enable workflow** в Actions |
| Много мусора или мало заявок | Подстройте `stop_words`, `weights` и `thresholds`, ориентируясь на «Score Reasons» в Notion |

Локальная проверка Python-версии:

```bash
pip3 install -r requirements-dev.txt
python3 -m pytest                                               # тесты без сети
PYTHONPATH=src python3 -m leadgen diagnose
PYTHONPATH=src python3 -m leadgen run --sources fl_ru --force   # dry-run по умолчанию
```
