# Интеграции приложения

Эти подключения настраиваются в «Настройках»: облачные диски — «Настройки → Данные → Облачные диски», почта и звонки — «Настройки → Почта и звонки». Окно «Коннекторы» (меню учётной записи) для них не нужно: встроенных коннекторов в приложении нет, каталог наполняют проверенные компании (см. [Коннекторы и Ai](Коннекторы-и-Ai)).

## Облачные диски

Здесь диски, к которым приложение подключается само, по кнопке «Подключиться». Диски, приложения которых уже установлены на Mac (их папки), по-прежнему в «Настройки → Данные → Облачное хранилище».

| Диск | Как подключается | Что нужно |
|---|---|---|
| Google Диск | вход через браузер (OAuth), доступ только к файлам, созданным приложением | ключи приложения Google в сборке (см. ниже) |
| Dropbox | вход через браузер (OAuth), отдельная папка приложения | ключ приложения Dropbox в сборке |
| OneDrive | вход через браузер (OAuth), папка приложения | ID приложения Microsoft в сборке |
| Яндекс Диск | WebDAV `https://webdav.yandex.ru`, логин и **пароль приложения** Яндекса (раздел «Файлы») | ничего |
| MEGA | WebDAV из бесплатного MEGAcmd: `mega-webdav /Customers` выдаёт адрес `http://127.0.0.1:4443/…` | установленный MEGAcmd (MEGA не даёт сторонним приложениям входить по логину) |
| pCloud | WebDAV `ewebdav.pcloud.com` (Европа) или `webdav.pcloud.com` (США) | ничего |
| WebDAV / Nextcloud | любой WebDAV-адрес https:// | ничего |

У подключённого диска есть кнопка «Выгрузить копию»: приложение делает свежую резервную копию базы и кладёт её в папку `Customers` на диске. Копия зашифрована ключом из Связки ключей этого Mac, как и рабочая база.

Безопасность: токены и пароли хранятся только в Связке ключей, отдельно для каждого пользователя приложения. WebDAV без шифрования (http://) разрешён только для адреса на этом же Mac (MEGAcmd). Вход через браузер идёт по OAuth 2.0 с PKCE; ответ браузера принимает сервер только на `localhost:47811`, со сверкой `state`.

### Ключ приложения: кнопка «Добавить ключ» (с версии 1.0.10.1)

У Google Диска, Dropbox и OneDrive, пока ключа нет, вместо «Подключиться» стоит кнопка **«Добавить ключ»**. В окне вводится ключ своего приложения (App key у Dropbox; Client ID и Client secret у Google; Application ID у Microsoft), рядом подсказка по шагам, ссылка на консоль и адрес возврата с кнопкой «Копировать». Ключ хранится только в Связке ключей этого Mac (общий для всех пользователей приложения на нём). У сохранённого ключа в меню «⋯» есть «Изменить ключ…» и «Удалить ключ» (удаление отключает и диски, подключённые с ним). Ключ, вшитый в сборку, главнее введённого и из приложения не меняется.

Создать приложение нужно один раз, бесплатно, в консоли сервиса. Можно вместо ввода в приложении передать ключи в сборку из настроек репозитория (Settings → Secrets and variables → Actions); в коде они не хранятся.

Адрес возврата у всех одинаковый: `http://localhost:47811/oauth/callback`.

1. **Dropbox** → [dropbox.com/developers/apps](https://www.dropbox.com/developers/apps) → Create app → Scoped access → **App folder** → имя, например «Customers». На вкладке Permissions включить `files.content.write`, нажать Submit. На вкладке Settings в «Redirect URIs» добавить адрес возврата. App key → переменная репозитория **`DROPBOX_APP_KEY`**. Секрет приложения не нужен (PKCE).
2. **Google Диск** → [console.cloud.google.com](https://console.cloud.google.com) → новый проект → «APIs & Services» → Library → включить **Google Drive API**. «OAuth consent screen»: External, добавить область `.../auth/drive.file`, в «Test users» добавить свой Gmail (или опубликовать приложение). Credentials → Create credentials → OAuth client ID → тип **Desktop app**. Client ID → переменная **`GOOGLE_OAUTH_CLIENT_ID`**, Client secret → секрет **`GOOGLE_OAUTH_CLIENT_SECRET`** (у приложений Desktop Google не считает его тайной, но храним в секретах).
3. **OneDrive** → [entra.microsoft.com](https://entra.microsoft.com) → App registrations → New registration → «Accounts in any organizational directory and personal Microsoft accounts» → Redirect URI: платформа **Public client/native (mobile & desktop)**, адрес возврата. API permissions → Microsoft Graph → Delegated → `Files.ReadWrite.AppFolder`, `offline_access`. Application (client) ID → переменная **`MICROSOFT_CLIENT_ID`**.

После этого ключи попадут в приложение со следующей сборкой из main или релизом.

## Почта

«Настройки → Обращения → Почта» → «Как отправлять письма»:

- **Через программу «Почта»** (по умолчанию). Кнопка «Открыть в Почте» во вкладке «Написать» создаёт готовое письмо в «Почте» (или в почтовой программе по умолчанию). Отправленные хранятся там и видны на всех устройствах. Ничего настраивать не нужно.
- **Прямо из приложения (SMTP).** Указать адрес: для Gmail, Яндекс Почты, Mail.ru и iCloud сервер и порт подставляются сами. Нужен **пароль приложения** (ссылка на страницу его создания есть рядом с полем), обычный пароль сервисы по SMTP не принимают. Соединение всегда шифруется (TLS на 465 или STARTTLS на 587), без шифрования приложение пароль не отправит. «Копия себе» кладёт письмо и в ваш ящик, так его видно в «Почте» на всех устройствах. Пароль — только в Связке ключей.

Письма уходят по одному, по кнопке. Каждое отправленное или подготовленное письмо записывается в «Историю» лида.

## Вкладка «Написать» в карточке лида

Бывшая вкладка «Обращение». Только Email: кому (адреса лида на выбор, можно вписать свой), тема и текст из шаблона, кнопки «Отправить» (если почта подключена по SMTP), «Открыть в Почте», «Копировать», «Вернуть черновик».

## Звонки

Во вкладке «Обзор» рядом с телефоном есть кнопка звонка, рядом с email — кнопка письма (открывает «Написать» с этим адресом). Звонок открывает FaceTime со ссылкой `tel:`: номер приводится к виду `+7…`, добавочный отбрасывается. Чтобы звонить по сотовой связи, на iPhone включите «Настройки → Телефон → Вызовы на других устройствах → этот Mac», а в FaceTime на Mac — «Вызовы с iPhone». Звонок записывается в «Историю» лида.
