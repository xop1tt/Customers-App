# Обновления и отчёты о сбоях

## Автообновление (с версии 1.0.5)

- С выбранной частотой (каждый час, 3, 6 или 12 часов, раз в сутки или раз в неделю; по умолчанию раз в сутки,
  с версии 1.0.6.1) приложение проверяет последний релиз через публичный API GitHub, без токена и учётной записи.
- Если вышла новая версия, приложение покажет, что в ней нового, и предложит **«Установить и перезапустить»**,
  **«Позже»** или **«Пропустить эту версию»**.
- Установка: скачивание dmg, сверка SHA-256, проверка, что внутри то же приложение нужной версии, замена и перезапуск.
  Если что-то не так, установленная версия остаётся.
- Если папка с приложением недоступна для записи, откроется dmg для ручной установки.
- Проверить вручную: меню **«Customers» → «Проверить обновления…»**. Частота и выключение проверки: «Настройки → Обновления».

Контрольная сумма берётся из того же релиза: она защищает от повреждённой или недокачанной загрузки, но не заменяет
подпись Apple. Подписи Apple Developer ID у сборки нет.

## Фоновая загрузка

- Найденное обновление скачивается **в фоне**, пока вы работаете: приложение не мешает и не перезапускается само.
  Когда файл скачан и проверен по SHA-256, в «Настройки → Обновления» (на Windows — «О программе») появляется
  кнопка **«Установить и перезапустить»**. Установка идёт только после вашего подтверждения.
- Фоновую загрузку можно выключить там же: тогда обновление скачивается по кнопке «Скачать» / «Обновить». Ручная проверка остаётся.
- На платном подключении (лимит трафика, роуминг) фоновая загрузка откладывается.
- Обрыв связи не страшен: загрузка продолжается с того места (Windows) или начинается заново (macOS), повторные попытки идут
  автоматически. Если места на диске мало, приложение сообщает, сколько нужно освободить. Установленная версия при любой ошибке остаётся нетронутой:
  скачанный файл ждёт отдельно и заменяет её только после успешной проверки.
- Скачанное обновление переживает перезапуск приложения: повторно качать не нужно. Если оно успело устареть, оно будет удалено.

## «Что нового» и первый запуск

- После обновления при первом запуске новой версии открывается окно **«Что нового в версии X.Y.Z?»** с короткими изменениями именно для вашей платформы
  (технические строки, README, вики, рефакторинг и ссылки на GitHub отбрасываются, родственные пункты собираются в темы и пересказываются коротко).
  Новые возможности показаны небольшими картинками в действии. Текст сохраняется перед установкой, поэтому показывается и без интернета.
  Окно показывается один раз для каждой версии и закрывается кнопкой.
- При первом входе в новую учётную запись запускается **мастер первой настройки**: описание возможностей → источники поиска → интеграции →
  облачные диски → оформление. Внешний вид применяется сразу, подключённое ранее видно как подключённое, любой необязательный шаг
  пропускается кнопкой, «Назад» возвращает на предыдущий шаг. После мастера открывается главная страница. Учётные записи с данными мастер не показывают.

Для Windows порядок тот же: установщик `Customers-vX.Y.Z-Windows-x64-Setup.exe` скачивается, сверяется по SHA-256 (дважды: после загрузки и перед запуском), ставится поверх с сохранением данных и сам открывает приложение снова. Оба файла и их `.sha256` лежат в одном релизе.

Полный список версий открыт на странице [Releases](https://github.com/xop1tt/Customers-App/releases); в самом приложении его нет.

## Отчёты о вылетах, зависаниях и ошибках

- После вылета или зависания приложение предлагает отправить отчёт macOS (`~/Library/Logs/DiagnosticReports`).
- Перед отправкой виден и правится весь текст. Домашняя папка и имя пользователя скрываются.
- Отправка: в браузере открывается новое обращение в [Issues](https://github.com/xop1tt/Customers-App/issues), которое отправляете вы. Само приложение никуда
  ничего не отправляет: в нём нет ни ключей, ни своего сервера.
- Ошибки поиска, экспорта и резервных копий пишутся в журнал на этом Mac: `~/Library/Logs/LeadGenerator`.
- Сообщить о проблеме вручную: меню **«Справка» → «Сообщить о проблеме…»**.
- Всё отключается в «Настройки → Отчёты».

Об уязвимостях не пишите в публичные Issues: см. [SECURITY.md](https://github.com/xop1tt/Customers-App/blob/main/SECURITY.md).
