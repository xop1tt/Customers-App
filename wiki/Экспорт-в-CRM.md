# Экспорт в CRM

Кнопка **«Экспорт в…»** над таблицей лидов (или **Файл → Экспорт в…**, ⇧⌘E) открывает окно с вкладками:
**Файл**, **Bitrix24**, **Notion**, **Вебхук**. Экспортируются выбранные лиды, а если ничего не выбрано, все лиды,
показанные в текущем разделе с учётом фильтров. Стрелка рядом с кнопкой сразу открывает нужную вкладку.

Все варианты бесплатные: Bitrix24 и Notion работают на бесплатных тарифах, вебхуки есть в бесплатных тарифах
Make, n8n, Zapier и Pipedream. Ключи и адреса вебхуков хранятся только в Связке ключей этого Mac, в Git, в облако
и в журналы не попадают. Отключить сервис можно кнопкой «Отключить» на его вкладке.

> Bitrix24 и Notion реализованы по их официальной документации API и проверены автотестами на разборе ответов,
> но не на живых порталах. Если что-то не работает, [сообщите о проблеме](https://github.com/xop1tt/Customers-App/issues/new)
> и приложите текст ошибки из окна экспорта (секретов в нём нет).

## Bitrix24

1. В Bitrix24 откройте **Разработчикам → Другое → Входящий вебхук**.
2. В правах отметьте **CRM (crm)** и сохраните.
3. Скопируйте адрес вида `https://ваш-портал.bitrix24.ru/rest/1/abc123…/` и вставьте его на вкладке Bitrix24.
4. «Проверить и подключить»: приложение запрашивает список полей лида, чтобы убедиться, что вебхук действует и у него есть доступ к CRM.

Каждый лид становится лидом CRM (`crm.lead.add`):

| Customers | Bitrix24 |
|---|---|
| Название | Название лида (TITLE) |
| Компания / заказчик | Название компании |
| Телефоны, email, сайт | Телефон, E-mail, Сайт (рабочие) |
| Адрес, регион | Адрес, город |
| Бюджет и валюта | Сумма и валюта |
| Описание, ссылка, источник, оценка, причины, заметка | Комментарий |
| — | Источник «Другое», описание источника «Customers: …» |

Запросы идут не чаще двух в секунду (лимит Bitrix24).

## Notion

1. Откройте [notion.so/my-integrations](https://www.notion.so/my-integrations) → **New integration** (тип Internal) и скопируйте ключ.
2. Откройте базу данных для лидов → **••• → Подключения** → добавьте эту интеграцию.
3. Скопируйте ссылку на базу (**••• → Скопировать ссылку**) и вставьте её вместе с ключом на вкладке Notion.

Приложение прочитает свойства базы и само сопоставит их по названиям («Название», «Телефон», «Email», «Сайт»,
«Город», «Оценка», «Источник» и т. д.). Сопоставление можно поменять в списке под заголовком; «Не заполнять»
пропускает свойство. Поддерживаются свойства типов заголовок, текст, ссылка, email, телефон, число, выбор, теги,
флажок и дата. Свойство-заголовок базы обязательно должно быть сопоставлено. Описание, ссылка и оценка лида
пишутся в текст страницы. Если в базу добавили свойства, нажмите «Обновить свойства базы».

## Вебхук (Make, n8n, Zapier, Pipedream, свой сервер)

Через сценарий с триггером «Webhook» лиды можно передать в amoCRM, Google Таблицы, Airtable, Trello и любые
другие сервисы, которые поддерживает сервис автоматизации. Адрес должен начинаться с `https://`.

Каждый лид уходит отдельным POST-запросом:

```json
{
  "event": "lead.exported",
  "source": "lead-generator",
  "lead_id": "…",
  "lead": {"title": "…", "phone": "…", "phones": ["…"], "emails": "…", "email_list": ["…"],
           "website": "…", "url": "…", "score": 72, "region": "…", "…": "все поля экспорта"}
}
```

Заголовок `X-LeadGen-Lead-Id` повторяет `lead_id`: по нему сценарий может отсеять повторы. Если сервер вернул
JSON с полем `id`, оно запоминается как номер записи.

## Защита от дублей

Приложение запоминает, какие лиды уже ушли в каждое назначение (отдельно для каждого портала, базы и адреса), и при
повторном экспорте пропускает их. Окно показывает, сколько выбранных лидов уже отправлено. Флажок «Отправить
повторно уже отправленные» отправит их ещё раз: в Bitrix24 и Notion это создаст новые записи, а не обновит старые.

Журнал отправленных лежит в локальной базе пользователя и не синхронизируется: на другом Mac лиды будут считаться
неотправленными.

## Ошибки

- **Доступ не подтверждён** — ключ или вебхук недействителен: создайте его заново и подключите снова.
- **Недостаточно прав** (Bitrix24) — у вебхука нет права «CRM (crm)».
- **Не найдено** (Notion) — база не подключена к интеграции: **••• → Подключения**.
- **Notion отклонил данные** — тип свойства не подходит к полю; поменяйте сопоставление.
- **Сервис просит подождать** — превышен лимит запросов; приложение повторяет запрос один раз, затем пропускает лид.

При ошибке доступа экспорт останавливается сразу. Остальные ошибки относятся к отдельным лидам: они перечислены в
окне, а успешно отправленные лиды запоминаются.
