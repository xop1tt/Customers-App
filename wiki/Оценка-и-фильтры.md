# Оценка и фильтры

Каждый лид получает оценку от 0 до 100 и категорию: **высокая**, **средняя**, **низкая** релевантность или
**не подходит**. Оценка считается собственными правилами (ключевые слова и веса), без AI API. Это оценка
системы, а не факт: причины начисления баллов видны в панели лида.

Правила оценки по умолчанию настроены на заказы на разработку: так проще всего проверить работу поиска. Для других
ниш используйте ключевые слова источников и [исключения](Работа-с-приложением#исключения), а при оценке смотрите на
причины баллов, а не только на число.

Перед оценкой срабатывает предфильтр по ключевым словам источника (см. [Источники](Источники)).
Лиды, попавшие под [исключения](Работа-с-приложением#исключения), уходят в раздел «Исключённые».

## Заказы (RSS, Telegram, VK)

| Критерий | Баллы по умолчанию | Как определяется |
|---|---|---|
| Стоп-слова | сразу «не подходит» | вакансии в штат, резюме, стажировки, казино, ставки, накрутки, «без оплаты», взлом, 18+ |
| Тематика разработки | до +30 | слова по типам: сайт, Telegram-бот, мобильное приложение, веб-приложение, автоматизация, CRM, доработка. Нет ни одного — «не подходит» |
| Явный запрос | +20 | «ищу», «нужен», «требуется», «кто сделает», «хочу заказать», «ТЗ»… |
| Похоже на предложение услуг | −35 | «сделаю», «разработаю», «беру заказы», «моё портфолио»… |
| Указан бюджет | +15 | разбирается из текста: «15 000 ₽», «бюджет до 20к», «$300» |
| Бюджет ниже 3000 ₽ | −10 | |
| Срочность | +5 | «срочно», «сегодня», «горит», «asap» |
| Подробное описание (от 40 слов) | +10 | короче 8 слов: −10 |
| Заказчик — бизнес | +5 | «ООО», «компания», «салон», «клиника», «магазин»… |
| Выполнимо одним разработчиком | +5 | «1С», Unity, embedded, смарт-контракты, «в офис»: −15 |
| Признаки спама | −40 | «пассивный доход», «промокод», «реферал», больше 5 ссылок |
| Свежая публикация (до суток) | +10 | старше 14 дней — «не подходит» |

Пороги категорий: высокая от 65, средняя от 45, низкая от 25, ниже — «не подходит».

## Организации (OpenStreetMap)

Оценка опирается только на проверенные сигналы проверки сайта:

| Сигнал | Баллы |
|---|---|
| Вес категории организации | база (10, если для категории вес не задан) |
| Сайт не указан в источнике | +35 |
| Сайт недоступен | +30 |
| Нет HTTPS | +10 |
| Нет мобильной вёрстки (meta viewport) | +15 |
| Сайт выглядит устаревшим (старый год в копирайте) | +15 |
| Нет онлайн-записи (предположение о потребности) | +10 |
| Есть публичный контакт | +10, нет контактов: −20 |

Пороги: высокая от 60, средняя от 40, низкая от 25.

## Дедупликация

Один и тот же заказ из разных источников или повторных публикаций не дублируется: сравниваются ID в источнике
и отпечаток текста, домена и телефона.

## Настройка весов

В приложении веса и словари пока фиксированные.
Подстроить выдачу можно ключевыми словами источника и исключениями.
