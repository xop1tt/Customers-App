# Установка

Customers есть для двух систем. Оба установщика лежат в одном релизе: [Releases → Latest](https://github.com/xop1tt/Customers-App/releases/latest) (рядом с каждым файлом лежит `.sha256`).

| Система | Файл | Требования |
|---|---|---|
| macOS | `Customers-vX.Y.Z-macOS.dmg` | macOS 12 Monterey и новее, Apple Silicon или Intel (сборка универсальная) |
| Windows | `Customers-vX.Y.Z-Windows-x64-Setup.exe` | Windows 10 версии 1809 и новее или Windows 11, 64-разрядная (x64) |

Ниже сначала macOS, затем [Windows](#windows). Один облачный аккаунт работает на обеих системах ([Учётные записи и облако](Учётные-записи-и-облако)).

# macOS

## Вариант 1. Установщик из релиза (рекомендуется)

1. Откройте [Releases → Latest](https://github.com/xop1tt/Customers-App/releases/latest) и скачайте `Customers-vX.Y.Z-macOS.dmg`.
2. Откройте dmg и перетащите «Customers» на ярлык «Программы».
3. Первый запуск: правый клик по приложению → **Открыть** → **Открыть**.
   Сборка подписана локально (ad-hoc), без платного Apple Developer ID, поэтому macOS один раз спрашивает подтверждение.
4. Создайте учётную запись (см. [Учётные записи и облако](Учётные-записи-и-облако)).
5. Добавьте свои Telegram-каналы, RSS-ленты или города в разделе «Источники» ([подробно](Источники)) и нажмите
   зелёную кнопку **«Найти лиды»** в центре верхней панели (⌘R).

Начиная с версии 1.0.5 следующие версии ставятся из самого приложения: см. [Обновления и отчёты о сбоях](Обновления-и-отчёты-о-сбоях).

### Обновление вручную

Скачайте новый dmg и перетащите приложение на «Программы» **с заменой**. Лиды, настройки и учётные записи
хранятся отдельно от приложения и не теряются.

### Свежая сборка из ветки

Сборка любой ветки или PR есть в **Actions → macOS app → Artifacts** (`Customers-macOS`, внутри dmg).
Для неё нужен вход на GitHub. Это тестовые сборки, автообновление их не трогает.

## Вариант 2. Сборка из исходников

Нужны Xcode 15+ или Command Line Tools (`xcode-select --install`).

```bash
git clone https://github.com/xop1tt/Customers-App.git
cd Customers-App/macos
swift test                                       # тесты: поиск, оценка, база, учётные записи
./scripts/build-app.sh                           # соберёт build/Customers.app
./scripts/make-dmg.sh build/Customers.dmg   # по желанию: установщик
open "build/Customers.app"
```

Чтобы в сборке появился вход по почте и синхронизация, перед сборкой задайте переменные `SUPABASE_URL` и
`SUPABASE_ANON_KEY` (см. [docs/cloud-setup.md](https://github.com/xop1tt/Customers-App/blob/main/docs/cloud-setup.md)). Без них приложение работает только
с локальными учётными записями.

Подробнее о структуре проекта: [Разработка и сборка](Разработка-и-сборка).

## Где лежат данные

| Что | Где |
|---|---|
| База лидов пользователя | `~/Library/Application Support/Lead Generator/users/<имя>/leads.db` (расположение можно сменить в «Настройки → Данные») |
| Резервные копии | папка, выбранная в «Настройки → Данные» |
| Журнал ошибок | `~/Library/Logs/LeadGenerator` |
| Ключ VK, запомненный вход, токены облака | Связка ключей macOS |

## Удаление (macOS)

Перетащите приложение из «Программ» в Корзину. Чтобы удалить и данные, удалите папку
`~/Library/Application Support/Lead Generator` (сначала сделайте резервную копию, если данные нужны).

# Windows

Права администратора, Visual Studio и .NET **не нужны** (нужна только среда WebView2: она входит в Windows 11 и в обновлённую Windows 10); приложение ставится для текущего пользователя.

1. Скачайте `Customers-vX.Y.Z-Windows-x64-Setup.exe` из [последнего релиза](https://github.com/xop1tt/Customers-App/releases/latest).
2. Запустите файл. Если SmartScreen пишет «Windows защитила ваш компьютер», нажмите **Подробнее → Выполнить в любом случае**:
   установщик без платной подписи Microsoft. Сумму можно сверить с файлом `.sha256`:
   `Get-FileHash .\Customers-vX.Y.Z-Windows-x64-Setup.exe -Algorithm SHA256`.
3. Выберите язык и папку (по умолчанию `%LOCALAPPDATA%\Programs\Customers`), при желании значок на рабочем столе.
4. Создайте учётную запись (локальную или облачную), добавьте источники и нажмите **«Найти лиды»**.

Тихая установка: `Customers-vX.Y.Z-Windows-x64-Setup.exe /VERYSILENT /CURRENTUSER /DIR="D:\Apps\Customers"`.

**Обновление.** Приложение раз в сутки проверяет последний релиз (отключается в «Настройки → О программе»), скачивает установщик и сверяет SHA-256. Можно и просто запустить новый установщик поверх старого. Данные не затрагиваются.

**Удаление.** Параметры Windows → Приложения → Customers → Удалить. Программа спросит, удалять ли данные (по умолчанию остаются). Резервные копии в «Документах» не удаляются никогда.

| Что | Где |
|---|---|
| Программа | `%LOCALAPPDATA%\Programs\Customers` |
| Данные (база, настройки, журналы) | `%LOCALAPPDATA%\Customers` |
| Ключи базы и токены | `%LOCALAPPDATA%\Customers\secrets`, защищены DPAPI |
| Резервные копии | `Документы\Customers Backups\<имя записи>` (меняется в настройках) |

> **Ключ базы привязан к учётной записи Windows (DPAPI).** При переустановке Windows или сбросе пароля без сохранения профиля база не откроется. Делайте резервные копии (они зашифрованы тем же ключом, поэтому тоже требуют его) и экспорт в CSV/JSON, либо используйте облачную учётную запись.

Работа в фоне: закрытие окна прячет приложение в область уведомлений, автозапуск включается в настройках. Диски, почта и звонки: [Интеграции](Интеграции-приложения). Сборка из исходников: [Разработка и сборка](Разработка-и-сборка#сборка-приложения-для-windows). Подробно: [windows/docs](https://github.com/xop1tt/Customers-App/tree/main/windows/docs).
