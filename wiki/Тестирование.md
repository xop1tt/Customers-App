# Тестирование

Эталонный уровень проверки: для каждого модуля и функции есть тесты основного сценария, граничных случаев, ошибок и безопасности. Правила изменения тестов: [Разработка и сборка → Тесты и проверки как эталон](Разработка-и-сборка).

## Карта покрытия: приложение (Swift)

Запускается `swift test` на macOS (GitHub Actions: macOS app, release). Облачный модуль и шифрование базы дополнительно собираются и проверяются на Linux (Cloud, libsqlcipher-dev).

## Карта покрытия: приложение для Windows (C#)

Проверки запускает workflow **Windows app** (`windows.yml`) и перед выпуском задача `windows` в `release.yml`. Подробный разбор: [windows/docs/testing.md](https://github.com/xop1tt/CLIENTS/blob/main/windows/docs/testing.md).

| Проверка | Где | Что проверяет |
|---|---|---|
| `Customers.Core.Tests` | Windows и Linux | оценка и дедупликация (совпадают с macOS на общих эталонных данных), источники на записанных ответах, база и шифрование SQLCipher, резервные копии, учётные записи, облако и синхронизация, экспорт и импорт, Bitrix24 и Notion, обновления, OAuth (PKCE, возврат на `localhost`), WebDAV и выгрузка на диски, SMTP и MIME |
| `Customers.Presentation.Tests` | Windows и Linux | модели представления: фильтры, выбор, фоновый поиск и отмена, копии, вход и выход, облако, восстановление повреждённой базы |
| Сборка и формат | Windows и Linux | предупреждения компилятора считаются ошибками; `dotnet format whitespace --verify-no-changes` |
| Сборка WinUI и публикация | Windows | XAML компилируется, приложение публикуется автономно |
| `Customers.exe --smoke` | Windows | реальный запуск: регистрация, все разделы и настройки, смена темы, экспорт и импорт, копии, живая смена акцента, WebDAV-выгрузка, возврат OAuth, почта и DPAPI, скрытие в трей и возврат, автозапуск, скриншоты |
| Установщик | Windows | установка без прав администратора, запуск, установка поверх с сохранением данных, удаление |

Не покрыто автоматически: внешний вид на живых Windows 10 и 11 с разными масштабами, реальный вход в Google, Dropbox и Microsoft, настоящий SMTP с TLS, внешний вид значка в трее и системные уведомления, полный цикл «релиз → обновление из приложения».

## Как проверяется то, что нельзя автоматизировать

- Bitrix24 и Notion проверены только по документации API и тестами на разборе ответов. Живые порталы и базы не проверялись.
- Значок в Dock, меню и окна проверяются вручную на Mac; значок в области уведомлений и вёрстка на Windows — вручную на Windows 10 и 11.
