# Тестирование

Эталонный уровень проверки: для каждого модуля и функции есть тесты основного сценария, граничных случаев, ошибок и безопасности. Правила изменения тестов: [Разработка и сборка → Тесты и проверки как эталон](Разработка-и-сборка).

## Карта покрытия: приложение (Rust + TypeScript)

Приложение одно для macOS и Windows, поэтому и проверки общие. Ядро (Rust) тестируется командой `cargo test` в `desktop/src-tauri`, интерфейс (React) командой `npm test` в `desktop`. В CI (`desktop.yml`) ядро проверяется на Linux, macOS и Windows, а перед выпуском те же тесты идут в `release.yml`.

| Модуль ядра | Что проверяется | Где |
|---|---|---|
| Модели лида (`models`) | JSON в формате Python-версии, терпимость к пропущенным и битым полям, email и телефоны, домен, ключи сортировки | `models.rs`, `util.rs`, `contact.rs` |
| Шифрование базы (`db`, `secrets`) | SQLCipher; ключ (формат, случайность, не попадает в сообщения); новая база и её копии без открытого текста; без ключа и с чужим ключом не открывается; перевод старой базы без потери данных; восстановление из зашифрованной, старой и чужой копии; ключ создаётся один раз и читается после перезапуска | `db.rs`, `secrets.rs` |
| Хранилище лидов (`store`) | сохранение и дубли, избранное, архив, удаление, заметки, просмотр, журналы, состояние источников, исключения, импорт CSV, резервные копии, перенос базы | `db.rs`, `app/data.rs` |
| Экспорт и CSV | значения всех полей, CSV с BOM и экранированием, защита от формул, JSON, разбор CSV | `export.rs`, `csvfmt.rs` |
| Учётные записи | облачный вход и выход, сессия переживает перезапуск, профиль, смена пароля (проверка на тестовом облаке) | `app/session.rs`, `cloud/auth.rs` |
| Поиск | оценка и причины, разбор RSS, Telegram, VK и OpenStreetMap на записанных ответах, настройки, каталог категорий, HTTP с лимитами и повторами, сбой источника не ломает остальные | `search/*.rs`, `app/search.rs` |
| Обновления, «Что нового», отчёты о сбоях | версии, выбор релиза, проверка SHA-256, разбор отчётов, вычистка личных данных | `updates.rs`, `app/update.rs`, `whatsnew.rs`, `reports.rs` |
| Экспорт CRM в файл | колонки и свои поля, CSV и Excel, обратная загрузка через импорт, фильтры и корзина, защита от формул, права | `workspace/export.rs` |
| Экспорт в CRM | адреса и вебхуки, поля Bitrix24, схема и сопоставление Notion, ответы и ошибки, журнал отправленных | `crm.rs` |
| Почта и связь | телефоны, ссылки `tel:` и `mailto:`, защита от подстановки заголовков, MIME и SMTP (AUTH, STARTTLS, отказы, копия себе) | `mail.rs`, `contact.rs` |
| Облачные диски | каталог, ключи сборки, вход с PKCE и state, токены, WebDAV, выгрузка, имя файла не выходит из папки | `drives.rs`, `app/integrations.rs` |
| Облако | вход и регистрация, лимиты писем, обновление сессии, журнал изменений, синхронизация между двумя устройствами через настоящий сервер | `cloud/*.rs`, `tests/stack.rs`, стенд `supabase/tests` |
| Настройки устройства и записи | значения по умолчанию, ограничение диапазонов, совместимость со старыми файлами | `prefs.rs`, `paths.rs` |

| Интерфейс | Что проверяется | Где |
|---|---|---|
| Компоненты | кнопки, переключатели, поля, меню, подсказки и диалоги: клавиатура, фокус, закрытие по Esc | `ui/kit.test.tsx` |
| Приложение | вход, главный экран, список лидов, выбор и панель справа, поиск и фильтры, настройки, окно экспорта (на демо-бэкенде) | `app/app.test.tsx` |
| Логика | фильтры и сортировка лидов, форматирование, источники, масштаб, акцент | `lib/*.test.ts` |

| Внешний вид | скриншоты в 1920×1080, 2560×1440, 3840×2160 (в том числе с масштабом 200%), на ноутбуке и в малых окнах: нет обрезки, наложений и горизонтальной прокрутки | `npm run shots` |
| Значок приложения | значок один и тёмный, буква C по центру и с ровными отступами, без наклона, нет светлого варианта и подмены значка | `tests/test_icon.py` |

В CI дополнительно: сборка универсального `Customers.app` (проверка, что внутри есть arm64 и x86_64 и зарегистрирована схема `leadgenerator://`), сборка `customers.exe`, а в релизе ещё установщик Windows: установка без прав администратора, установка поверх с сохранением данных и удаление (`installer/check.ps1`).

Не покрыто автоматически: внешний вид в настоящем окне на живых macOS и Windows 10/11 с разными масштабами, реальный вход в Google, Dropbox и Microsoft, настоящий SMTP с TLS, значок в трее и системные уведомления, полный цикл «релиз → обновление из приложения».

## Проверки репозитория

`python3 -m pytest` из корня: права и закрепление действий в workflow (`test_workflows.py`), release-check
(`test_release_check.py`), иконки, имена миграций, гигиена репозитория. Каталог категорий OpenStreetMap проверяется
тестами Rust (`search/settings.rs`).

## Как проверяется то, что нельзя автоматизировать

- Bitrix24 и Notion проверены только по документации API и тестами на разборе ответов. Живые порталы и базы не проверялись.
- Значок в Dock, меню и окна проверяются вручную на Mac; значок в области уведомлений и вёрстка на Windows — вручную на Windows 10 и 11.
