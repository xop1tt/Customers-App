# Установка

## Требования

* Windows 10 версии 1809 (17763) или новее, либо Windows 11; 64-разрядная система (x64).
* Права администратора **не нужны**: приложение ставится для текущего пользователя.
* Visual Studio, .NET SDK и среда выполнения .NET или Windows App SDK **не нужны** — всё нужное лежит в установщике.
* Интернет нужен только для поиска, облачной синхронизации и проверки обновлений. Без него работают все остальные функции.

## Установка

1. Скачайте `Customers-vX.Y.Z-Windows-x64-Setup.exe` со страницы [последнего релиза](https://github.com/xop1tt/CLIENTS/releases/latest).
2. Запустите файл. Если SmartScreen пишет «Windows защитила ваш компьютер», нажмите **Подробнее → Выполнить в любом случае**:
   установщик не имеет платной подписи Microsoft (так же, как приложение для macOS не имеет платной подписи Apple).
   Контрольную сумму можно сверить с файлом `…Setup.exe.sha256` рядом с установщиком:
   `Get-FileHash .\Customers-vX.Y.Z-Windows-x64-Setup.exe -Algorithm SHA256`.
3. Выберите язык, папку (по умолчанию `%LOCALAPPDATA%\Programs\Customers`) и, если нужно, значок на рабочем столе.
4. Запустите Customers, создайте учётную запись (локальную или облачную) и добавьте источники.

Тихая установка для администраторов: `Customers-vX.Y.Z-Windows-x64-Setup.exe /VERYSILENT /CURRENTUSER /DIR="D:\Apps\Customers"`.

## Обновление

* Приложение раз в сутки проверяет последний релиз на GitHub (можно выключить: **Настройки → О программе**) и предлагает обновиться.
  Установщик скачивается и проверяется по SHA-256; при несовпадении обновление отменяется.
* Можно просто запустить новый установщик поверх старого. Приложение будет закрыто и запущено снова.
* **Данные при обновлении не затрагиваются**: они лежат отдельно от программы.

## Удаление

**Параметры Windows → Приложения → Установленные приложения → Customers → Удалить.**
Программа спросит, удалять ли данные. По умолчанию они остаются, и при повторной установке вы продолжите с того же места.
Резервные копии в «Документах» не удаляются никогда.

## Где что лежит

| Что | Где |
|---|---|
| Программа | `%LOCALAPPDATA%\Programs\Customers` |
| Данные (база лидов, настройки, журналы) | `%LOCALAPPDATA%\Customers` |
| Защищённые секреты (ключи базы, токены) | `%LOCALAPPDATA%\Customers\secrets`, зашифрованы DPAPI для вашей учётной записи Windows |
| Резервные копии | `Документы\Customers Backups\<имя записи>` (можно сменить в настройках) |

Базу можно перенести в другую папку (**Настройки → Данные**).

> **Важно про ключ базы.** База зашифрована, а её ключ защищён DPAPI и привязан к вашей учётной записи Windows. Если переустановить Windows или
> сбросить пароль учётной записи Windows без сохранения профиля, ключ будет потерян и сама база не откроется. Поэтому делайте резервные копии
> (они тоже зашифрованы тем же ключом) или используйте облачную учётную запись — тогда данные можно получить заново с сервера.
