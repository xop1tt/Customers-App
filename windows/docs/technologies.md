# Технологии

| Задача | Выбор | Почему |
|---|---|---|
| Язык | C# 14 | родной язык WinUI и .NET |
| Платформа | .NET 10 (текущий LTS) | долгая поддержка, автономная публикация без установки среды |
| Интерфейс | WinUI 3 + Windows App SDK 1.8 | нативные элементы Windows 11 (Fluent 2, Mica, закруглённые углы), работает и на Windows 10 |
| Разметка | XAML там, где она проще (оболочка, список, карточка лида), остальное — код | меньше связей по `x:Bind`, ошибки видны компилятору |
| База | SQLite + SQLCipher (`Microsoft.Data.Sqlite.Core`, `SQLitePCLRaw.bundle_e_sqlcipher`) | один файл, шифрование данных на диске, как в macOS-версии |
| Секреты | DPAPI (`System.Security.Cryptography.ProtectedData`) | защита ключом учётной записи Windows, без паролей на диске |
| Облако | Supabase Auth + REST по HTTPS (без SDK) | тот же сервис, что у macOS; никаких платных библиотек |
| Тесты | xUnit, coverlet | стандарт .NET |
| Установщик | Inno Setup 6 | бесплатный, установка без прав администратора, штатное удаление |
| CI | GitHub Actions (`windows-latest`, `ubuntu-24.04`) | без внешних сервисов |

Сознательно **не** используются: экспериментальные API, платные пакеты и API, сторонние библиотеки интерфейса (кроме Windows App SDK), обязательные внешние сервисы.
Все внешние источники данных — публичные и бесплатные (RSS, веб-превью Telegram, VK API с бесплатным ключом, OpenStreetMap Overpass).

## Совместимость с Windows 10

* Минимум — Windows 10 1809 (`TargetPlatformMinVersion=10.0.17763`).
* Mica есть только в Windows 11. На Windows 10 приложение автоматически берёт акрил, а если и он недоступен — обычный фон; выбор материала в настройках подсказывает, что получится.
* Закруглённые углы окон и элементов — штатная возможность системы: в Windows 10 углы прямые, это нормально.
* Системные уведомления и ссылки `leadgenerator:` работают в обеих системах.
