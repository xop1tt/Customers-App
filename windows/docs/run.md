# Запуск

Обычный запуск — ярлык «Customers» в меню «Пуск». Приложение работает в одном экземпляре: повторный запуск (и ссылка `leadgenerator://…` из письма) выводит на передний план уже открытое окно.

## Командная строка

| Параметр | Действие |
|---|---|
| `--data <папка>` | хранить данные в другой папке (по умолчанию `%LOCALAPPDATA%\Customers`), например для проверки на чистых данных |
| `--smoke <папка>` | проверочный запуск: окно открывается на чистых данных, приложение само проходит по всем разделам, пишет результат и снимки экрана в папку и завершается с кодом 0 или 1 |
| `leadgenerator://…` | ссылка подтверждения или восстановления пароля из письма |

Из исходников: `dotnet run --project src/Customers.App -r win-x64 -- --data C:\Temp\customers-dev`.

## Журналы и сбои

* Журналы: `%LOCALAPPDATA%\Customers\logs` (хранятся 14 дней, секреты и пароли в них маскируются).
* При необработанной ошибке приложение пишет отчёт о сбое в ту же папку и при следующем запуске предлагает его открыть. Данные при этом защищены:
  изменения записываются в базу сразу, а при открытии база проверяется; если она не открывается, показывается экран восстановления из резервной копии.

## Облако

Адрес и публичный ключ Supabase подставляются при сборке из переменных окружения `SUPABASE_URL` и `SUPABASE_ANON_KEY` (в CI — из переменных репозитория, как у macOS-версии).
Сборка без них работает только с локальными учётными записями.
