# Состояние Windows-версии

Документ ведётся честно: что сделано, что проверено, чего нет. Подтверждённые проверки CI смотрите в Actions → Windows app.

## Перенесено из macOS-версии

Поиск (RSS/Atom, публичные Telegram-каналы, VK, OpenStreetMap с проверкой сайтов), оценка 0–100 с причинами, дедупликация, фильтры и исключения, локальная база с шифрованием, избранное, заметки, история, черновик письма и ссылки tel/mailto, журнал запусков и ошибок, управление источниками и сброс их памяти, архив, экспорт и импорт CSV/JSON, Bitrix24, Notion, вебхук, резервные копии (ежедневные и ручные, восстановление, перенос базы, проверка целостности), настройки поиска, локальные и облачные учётные записи, смена и восстановление пароля, перенос локальной записи в облако, облачная синхронизация, обновление из приложения, облачные диски (Google Диск, Dropbox, OneDrive, Яндекс Диск, pCloud, MEGA, WebDAV/Nextcloud) с выгрузкой копий, отправка писем по SMTP, звонки по `tel:`, значок в области уведомлений с работой после закрытия окна и автозапуском, смена акцентного цвета без перезапуска (см. [integrations.md](integrations.md)).

## Только в Windows-версии

Установщик без прав администратора и удаление через «Приложения», материалы окна Mica / Mica Alt / Acrylic с запасными вариантами для Windows 10, системные уведомления, регистрация ссылок `leadgenerator:`, защита ключей через DPAPI, экран восстановления повреждённой базы, режим проверки `--smoke`.

## Не перенесено

| Что | Почему |
|---|---|
| iCloud Drive как отдельный диск | в Windows нет API iCloud для сторонних программ; папку копий можно указать внутри папки iCloud для Windows |
| Подпись установщика сертификатом | платная; SmartScreen при первом запуске предупреждает (см. [install.md](install.md)) |

## Известные ограничения

* **Ключ базы привязан к учётной записи Windows (DPAPI).** При потере профиля Windows база не откроется — нужна резервная копия (она зашифрована тем же ключом, то есть тоже требует ключа) или облачная запись. Для локальной записи без облака стоит периодически делать экспорт в CSV/JSON — он не зашифрован и открывается где угодно.
* **Экспорт и повторный импорт.** В набор полей экспорта по умолчанию (как и в macOS-версии) не входят ID и описание, поэтому импорт такого файла на другом компьютере создаёт лиды заново. Чтобы перенос не создавал дублей, включайте в экспорт поля «ID» и «Описание» («Все поля»).
* **Ключи OAuth создаёт владелец проекта.** Без ключей Google Диск, Dropbox и OneDrive предлагают «Добавить ключ»; Яндекс Диск, pCloud, MEGA и WebDAV работают без ключей. См. [integrations.md](integrations.md).
* **Не проверено автоматически:** реальный вход в Google, Dropbox и Microsoft и отправка через настоящий SMTP-сервер с TLS. В CI проверены протокол и разбор ответов на записанных ответах, вход через `localhost`, загрузка по WebDAV и отправка на поддельный SMTP; перекраску реальной кнопки, скрытие и возврат окна, пункты меню значка и запись автозапуска проверяет smoke-тест на runner Windows. Создан ли значок в трее, он лишь записывает в журнал (на runner может не быть панели задач), а как значок и меню выглядят на живом рабочем столе, проверяется только вручную.
* **Меню значка** — штатное меню Windows (`TrackPopupMenu`), а не WinUI-flyout: оно соответствует стилю системы, но не меняет тему вместе с приложением.
* **Mica** есть только в Windows 11; в Windows 10 используется акрил или обычный фон.
* **Проверка вёрстки** выполнена скриншотами из smoke-теста и не заменяет осмотр на живых Windows 10 и 11 с разными масштабами экрана.
* Приложение 64-разрядное (x64); ARM64 и 32-разрядные системы не поддерживаются.
* **Масштаб Windows 100–200 %** обеспечивается адаптивной вёрсткой (строки настроек, поля и кнопки переносятся под текст, список разделов настроек сворачивается до значков, карточка лида скрывается, когда не помещается рядом со списком, главная перестраивается в 2×2 и в столбик). Эти пороги проверены только рассуждением и сборкой в CI, а не глазами на каждом масштабе — осмотр на живой Windows 11 при 100, 125, 150, 175 и 200 % остаётся за вами.
* **Кнопка «Приложение по умолчанию» (звонки)** открывает «Параметры → Приложения по умолчанию» с параметром для ссылок tel:. Документированного перехода именно к протоколу TEL у Windows нет: на сборках, где параметр не поддерживается, открывается общий список приложений.
