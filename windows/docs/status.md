# Состояние Windows-версии

Документ ведётся честно: что сделано, что проверено, чего нет. Подтверждённые проверки CI смотрите в Actions → Windows app.

## Перенесено из macOS-версии

Поиск (RSS/Atom, публичные Telegram-каналы, VK, OpenStreetMap с проверкой сайтов), оценка 0–100 с причинами, дедупликация, фильтры и исключения, локальная база с шифрованием, избранное, заметки, история, черновик письма и ссылки tel/mailto, журнал запусков и ошибок, управление источниками и сброс их памяти, архив, экспорт и импорт CSV/JSON, Bitrix24, Notion, вебхук, резервные копии (ежедневные и ручные, восстановление, перенос базы, проверка целостности), настройки поиска, локальные и облачные учётные записи, смена и восстановление пароля, перенос локальной записи в облако, облачная синхронизация, обновление из приложения.

## Только в Windows-версии

Установщик без прав администратора и удаление через «Приложения», материалы окна Mica / Mica Alt / Acrylic с запасными вариантами для Windows 10, системные уведомления, регистрация ссылок `leadgenerator:`, защита ключей через DPAPI, экран восстановления повреждённой базы, режим проверки `--smoke`.

## Не перенесено

| Что | Почему |
|---|---|
| Подключение дисков и облачных хранилищ для копий (Dropbox, Google Диск, Яндекс Диск, OneDrive, iCloud) через вход в аккаунт, отправка писем и звонки из приложения через сервисы | требуют OAuth-ключей, которые создаёт владелец проекта в консолях Google, Microsoft и Dropbox; без них функции были бы «заглушками». Обходной путь: папку копий можно указать внутри синхронизируемой папки (OneDrive, Dropbox, Google Диск для компьютера) |
| Меню в области уведомлений (аналог строки меню macOS) и работа после закрытия окна | в WinUI 3 нет штатного значка в трее; без сторонних библиотек не делается. Автопоиск работает, пока приложение открыто |
| Подпись установщика сертификатом | платная; SmartScreen при первом запуске предупреждает (см. [install.md](install.md)) |

## Известные ограничения

* **Ключ базы привязан к учётной записи Windows (DPAPI).** При потере профиля Windows база не откроется — нужна резервная копия (она зашифрована тем же ключом, то есть тоже требует ключа) или облачная запись. Для локальной записи без облака стоит периодически делать экспорт в CSV/JSON — он не зашифрован и открывается где угодно.
* **Акцентный цвет** применяется ко всем стандартным элементам после перезапуска приложения (в настройках есть кнопка).
* **Mica** есть только в Windows 11; в Windows 10 используется акрил или обычный фон.
* **Проверка вёрстки** выполнена скриншотами из smoke-теста и не заменяет осмотр на живых Windows 10 и 11 с разными масштабами экрана.
* Приложение 64-разрядное (x64); ARM64 и 32-разрядные системы не поддерживаются.
