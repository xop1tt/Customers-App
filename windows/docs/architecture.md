# Архитектура

Три проекта с односторонними зависимостями: `Customers.App` → `Customers.Presentation` → `Customers.Core`. Нижний слой ничего не знает о верхних.

```
Customers.App            WinUI 3: окна, страницы, диалоги, уведомления, обновление, DPAPI-хранилище
   │  (типы интерфейса живут только здесь)
Customers.Presentation   модели представления: состояние приложения, сеанс, синхронизация, команды
   │  (нет ссылок на WinUI → тестируется на Linux и Windows)
Customers.Core           вся бизнес-логика: поиск, оценка, база, облако, экспорт, учётные записи
```

## Модули

| Модуль | Где | Что делает |
|---|---|---|
| Интерфейс | `Customers.App/Views`, `Settings`, `Infrastructure` | оболочка с тремя панелями, список лидов, карточка, главная, источники, журнал запусков, 13 страниц настроек, вход, экран ошибки базы |
| Логика представления | `Customers.Presentation` | `AppModel` (данные, фильтры, выбор, поиск в фоне, резервные копии, экспорт, CRM), `SessionModel` (вход, выход, облако), `CloudSyncController`, `DevicePreferences`, `AccountPreferences` |
| База данных | `Core/Storage` | `LeadStore` на SQLite + SQLCipher, миграции, журнал изменений для облака, целостность, перенос и восстановление |
| Поиск лидов | `Core/Search` | RSS/Atom, публичные Telegram-каналы, VK, OpenStreetMap (Overpass) с проверкой сайтов; интервалы источников, отмена, память источника |
| Оценка | `Core/Scoring`, `Core/Text` | оценка 0–100 с причинами, дедупликация (ID и отпечатки), фильтры, исключения |
| Авторизация | `Core/Security`, `Core/Cloud/CloudAuth.cs` | локальные учётные записи (PBKDF2-SHA256, лимит попыток), Supabase Auth |
| Облако | `Core/Cloud` | синхронизация лидов, исключений и настроек через Supabase REST |
| Интеграции | `Core/Export` | CSV/JSON, Bitrix24, Notion, вебхук, ссылки tel/mailto |
| Настройки | `Presentation/*Preferences.cs`, `App/Settings` | настройки компьютера (`device.json`) и учётной записи (`prefs.json`, плюс синхронизируемые поиск и подпись в базе) |
| Диски, почта | `Core/Integrations`, `Presentation/IntegrationsModel.cs`, `MailModel.cs`, `App/Settings/DrivesPage.cs`, `MailPage.cs` | OAuth 2.0 PKCE и WebDAV для выгрузки копий, SMTP с TLS; секреты в DPAPI |
| Фон | `App/Infrastructure/TrayIcon.cs`, `BackgroundHost.cs`, `AutoStart.cs` | значок в области уведомлений (Win32), скрытие окна, автозапуск с `--background` |
| Резервные копии | `Core/Util/Backups.cs`, `AppModel.Data.cs` | ежедневные и ручные копии, хранение N последних, восстановление с предохранительной копией |

## Принципы

* **Один источник логики.** Алгоритмы повторяют macOS-версию и проверяются теми же эталонными значениями (идентификаторы и отпечатки лидов, оценка, формат JSON), см. [macos-sync.md](macos-sync.md).
* **Интерфейс не блокируется.** Поиск идёт на отдельном соединении с базой в фоновой задаче и отменяется кнопкой «Остановить»; сеть, файловые и облачные операции асинхронны. Результаты возвращаются в поток интерфейса через `IUiDispatcher`.
* **Данные защищены.** База зашифрована (SQLCipher); ключ — случайный, у каждой учётной записи свой, хранится зашифрованным DPAPI. Токены и ключи интеграций тоже в DPAPI-хранилище, в журналах секреты маскируются.
* **Ошибки не прячутся.** Исключения источников собираются в отчёт поиска и показываются; необработанные сбои пишутся в журнал и отчёт о сбое, интерфейс продолжает работать.
* **Восстановимость.** Изменения пишутся в базу сразу; база проверяется при открытии; при сбое открытия показывается экран восстановления из копии; удаление данных всегда с предварительной копией.
* **Один экземпляр приложения.** Второй запуск (и ссылка из письма) передаётся первому через именованный канал.

## Внешний вид

* Три панели: навигация (скрывается, ширину можно менять), список с поиском и фильтрами, карточка лида (скрывается, ширина меняется). Размеры запоминаются.
* Оформление: тема светлая/тёмная/системная, материал окна Mica / Mica Alt / Acrylic / без материала с автоматическим запасным вариантом, акцентный цвет (применяется сразу), компактный список, отключение анимаций.
* Элементы Fluent: `NavigationView`, `CommandBar`, `InfoBar`, `ContentDialog`, `TeachingTip`, контекстные меню; состояния загрузки, ошибки и пустого списка.
