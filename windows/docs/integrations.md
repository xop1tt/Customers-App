# Диски, почта, звонки и работа в фоне (Windows)

Функции повторяют macOS-версию (см. [wiki/Интеграции-приложения.md](../../wiki/Интеграции-приложения.md)); ключи приложений и адрес возврата те же, поэтому один набор ключей работает на обеих платформах.

## Облачные диски: «Настройки → Облачные диски»

| Диск | Как подключается | Что нужно |
|---|---|---|
| Google Диск | вход через браузер (OAuth 2.0 + PKCE), доступ только к файлам приложения | ключ приложения (Client ID и Client secret) |
| Dropbox | вход через браузер, отдельная папка приложения | App key |
| OneDrive | вход через браузер, папка приложения | Application (client) ID |
| Яндекс Диск | WebDAV `https://webdav.yandex.ru`, логин и пароль приложения Яндекса | ничего |
| pCloud | WebDAV `ewebdav.pcloud.com` или `webdav.pcloud.com` | ничего |
| MEGA | WebDAV из бесплатного MEGAcmd (`mega-webdav /Customers`) | установленный MEGAcmd |
| WebDAV / Nextcloud | любой адрес `https://` | ничего |

Кнопка «Выгрузить копию» делает свежую резервную копию базы и кладёт её в папку `Customers` на диске. Копия зашифрована ключом базы (DPAPI), как и рабочая база.

Токены и пароли хранятся только в DPAPI-хранилище, отдельно для каждой учётной записи приложения. WebDAV по `http://` разрешён только для адресов этого компьютера (MEGAcmd). Вход через браузер принимает сервер на `localhost:47811` (IPv4 и IPv6) со сверкой `state`.

### Ключи OAuth

Приложение в консоли создаётся один раз и бесплатно. Адрес возврата у всех: `http://localhost:47811/oauth/callback`. Подробные шаги для Dropbox, Google и Microsoft — в [wiki/Интеграции-приложения.md](../../wiki/Интеграции-приложения.md) (раздел «Ключ приложения»).

Ключи можно передать двумя путями:

1. **В сборку.** Переменные репозитория `GOOGLE_OAUTH_CLIENT_ID`, `DROPBOX_APP_KEY`, `MICROSOFT_CLIENT_ID` и секрет `GOOGLE_OAUTH_CLIENT_SECRET` (Settings → Secrets and variables → Actions). Те же переменные использует сборка macOS; в `windows.yml` и в общем `release.yml` они попадают в шаги сборки и публикации и вшиваются в `Customers.App.dll` как `AssemblyMetadata`.
2. **В приложении.** Пока ключа нет, вместо «Подключиться» стоит «Добавить ключ»; он хранится в DPAPI. Вшитый ключ главнее введённого.

## Почта: «Настройки → Почта»

* **Почтовая программа Windows** — письмо открывается готовым черновиком (`mailto:`).
* **Отправка из приложения (SMTP)** — Gmail, Яндекс, Mail.ru, iCloud подставляют сервер сами, для остальных сервер, порт и шифрование задаются вручную. Шифрование обязательно (TLS или STARTTLS, сертификат проверяется), нужен пароль приложения; хранится в DPAPI. Письма уходят по одному, по кнопке; массовой рассылки нет. В журнал попадает только `сервер:порт`.

## Звонки: «Настройки → Звонки»

Кнопка «Позвонить» в карточке лида открывает ссылку `tel:` в приложении, выбранном в Windows («Связь с телефоном», Teams, Skype и т. п.). Страница показывает найденные приложения, позволяет включить подтверждение перед набором и сделать пробный вызов; если обработчика нет, карточка сообщает об этом и ведёт в настройки.

## Работа в фоне: «Настройки → Работа в фоне»

* **Значок в области уведомлений.** Создаётся через `Shell_NotifyIcon`; меню: «Открыть», «Найти сейчас» / «Остановить поиск», «Новые лиды: N», «Настройки», «Выйти». Подсказка значка показывает число новых лидов. Значок возвращается после перезапуска Проводника.
* **Закрытие окна** (крестик) прячет приложение в трей; автопоиск и резервные копии продолжаются. Выход — «Выйти» в меню значка. При первом сворачивании показывается пояснение. Переключатель «Закрытие окна прячет в область уведомлений» отключает поведение.
* **Автозапуск** — запись `HKCU\...\Run` с параметром `--background`; с «Запускать свёрнутым» окно при входе в Windows не показывается.
* Программе не мешает установщик: окно-приёмник значка отвечает на `WM_QUERYENDSESSION`, поэтому обновление и удаление корректно закрывают фоновый процесс.

## Акцентный цвет без перезапуска

Цвет из «Настройки → Внешний вид» применяется сразу: кисти `AccentFillColor*` и `AccentTextFillColor*` создаются один раз в словарях тем приложения и дальше меняют только свой цвет, поэтому уже показанные кнопки, переключатели, ссылки и выделение перекрашиваются на месте. «По умолчанию» берёт акцент Windows и следит за его изменением в «Параметры → Персонализация → Цвета».
