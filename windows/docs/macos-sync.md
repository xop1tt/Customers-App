# Обмен данными с версией для macOS

Windows и macOS используют **один и тот же облачный проект Supabase и те же таблицы**. Никакие таблицы, политики RLS, функции и миграции Supabase для Windows не менялись и не добавлялись: клиент использует уже существующие `sync_*` функции и таблицы из `supabase/migrations`.

## Что общее

| | |
|---|---|
| Облачная учётная запись | та же (вход по почте); войдите на обеих платформах под одним адресом |
| Лиды, отметки, заметки, история, избранное, архив | синхронизируются; конфликт полей решает более позднее изменение |
| Исключения | синхронизируются |
| Настройки поиска и подпись | синхронизируются (JSON с теми же именами полей, что у macOS) |
| Идентификатор лида и отпечатки для дедупликации | вычисляются одинаково, поэтому один лид на двух устройствах остаётся одним |
| Файлы экспорта CSV/JSON | совместимы в обе стороны |

## Что остаётся только на устройстве

Локальные учётные записи (имя и пароль), ключи VK, токены и вебхуки Bitrix24/Notion, пароль и сессия входа, ключ шифрования базы, внешний вид и размеры панелей. Секреты по облаку не передаются.

## Как перейти с macOS (и обратно)

1. На macOS войдите в облачную запись и дождитесь статуса «Синхронизировано».
2. На Windows войдите в ту же запись — лиды загрузятся автоматически.
3. Если данные были в локальной записи, перенесите их в облако: **Настройки → Учётная запись → Перенести в облако** (на macOS — аналогичный пункт). Исходная база не изменяется, перед переносом делается копия.

Сверку можно сделать в **Настройки → Облачная синхронизация → Сверить**.

## Единая логика

Общего исходного кода у Swift и C# нет, поэтому «одинаковость» обеспечивается тестами: те же входные данные и эталонные значения (идентификаторы, оценка, отпечатки, формат JSON синхронизации) проверяются в `Customers.Core.Tests`. Если правила оценки или формат меняются в macOS-версии, соответствующий тест на Windows должен быть обновлён вместе с ними.
