# Customers для macOS

Нативное приложение на SwiftUI (macOS 14 Sonoma и новее). Ищет потенциальных заказчиков прямо на вашем Mac:
без GitHub Actions, токенов GitHub и платных сервисов. Лиды, настройки и учётные записи хранятся только на этом Mac.

## Как это устроено

```
Customers.app
  ├─ Вход: локальная учётная запись (имя пользователя + пароль)
  ├─ Поиск (модуль LeadSearch, без интерфейса)
  │    RSS-ленты · Telegram-каналы · VK-сообщества · OpenStreetMap + проверка сайтов
  │    → оценка по правилам → дедупликация (ID и отпечаток текста/домена/телефона)
  └─ База пользователя: ~/Library/Application Support/Lead Generator/users/<имя>/leads.db
```

- Поиск запускается зелёной кнопкой **«Найти лиды»** в центре верхней панели (⌘R) или кнопкой
  «Проверить сейчас» у отдельного источника. Пока приложение открыто, оно само проверяет источники,
  у которых подошёл интервал (по умолчанию раз в час, меняется в настройках «Поиск»).
- У каждого источника своя память: какие записи уже прочитаны, какие запросы к OpenStreetMap выполнялись,
  какие сайты проверены. Повторный поиск не тратит запросы на уже обработанное.
- Поиск никогда не перезаписывает избранное, архив, заметки, удаления и исключения.

### Задел под сервер

Поиск вынесен в отдельный модуль `LeadSearch`, который не зависит от интерфейса:

- `SearchEngine` получает настройки, транспорт (`HTTPTransport`) и хранилище (`SearchRepository`);
- настройки источников (`SearchSettings`) хранятся как JSON — тот же формат сможет читать сервер;
- вход идёт через протокол `AuthService`; сейчас его реализует `LocalAuthService`.

Чтобы перенести поиск на сервер и не держать Mac включённым, достаточно запустить тот же `SearchEngine`
на сервере со своим хранилищем и заменить `LocalAuthService` на вход по сети. Это следующий этап.

## Учётные записи

- Регистрация и вход по имени пользователя (не почте) и паролю. Имя: 3–32 символа, буквы, цифры, `.`, `-`, `_`.
- Пароль не хранится: только соль и хэш PBKDF2-SHA256 (310 000 итераций). После 5 неверных попыток вход
  ненадолго блокируется.
- У каждого пользователя своя база лидов, свои настройки источников, свой ключ VK и свои резервные копии.
- «Запомнить вход» сохраняет имя пользователя в Связке ключей macOS. Выйти: меню у имени внизу боковой
  панели, «Лиды → Выйти из учётной записи» или «Настройки → Учётная запись».
- Забытый пароль восстановить нельзя: учётные записи локальные. Делайте резервные копии базы.
- При первой регистрации лиды из версии 1.0.x переносятся в новую учётную запись. Исходный файл остаётся
  рядом как `leads-1.0-backup.db`.

## Облачная учётная запись (необязательно)

Если сборка сделана с адресом облака (переменные `SUPABASE_URL` и `SUPABASE_ANON_KEY`, см.
[docs/cloud-setup.md](../docs/cloud-setup.md)), на экране входа появляется вход по электронной почте:

- регистрация с подтверждением почты кодом из письма, вход, выход, восстановление и смена пароля,
  смена адреса (подтверждаются оба адреса), удаление учётной записи;
- лиды и отметки, исключения, настройки поиска синхронизируются между вашими Mac;
- без сети всё работает локально, изменения уйдут в облако позже; статус — внизу боковой панели;
- токены входа лежат в Связке ключей, пароль на Mac не сохраняется;
- данные локальной учётной записи можно перенести: «Настройки → Учётная запись».

Локальные учётные записи остаются: «Работать без облака» на экране входа. Подробности: [docs/cloud.md](../docs/cloud.md).

## Источники

Раздел **«Источники»**: слева список, справа настройки выбранного источника.

| Источник | Доступ | Что настраивается |
|---|---|---|
| RSS-ленты | Бесплатно | любые публичные RSS/Atom-ленты (например, FL.ru), ключевые слова |
| Telegram-каналы | Бесплатно | каналы (только публичные, с веб-превью `t.me/s/…`), страниц за запуск, ключевые слова |
| VK-сообщества | Бесплатный ключ | сервисный ключ VK, сообщества, страниц за запуск, ключевые слова |
| OpenStreetMap | Бесплатно | города и регионы, категории организаций, проверка сайтов, лимиты |

Для каждого источника: включение, интервал проверки, «Проверить сейчас», «Начать заново» (забыть
прочитанное), состояние и журнал ошибок в правой панели.

Списки (ключевые слова, каналы, ленты, сообщества, регионы) пополняются тремя способами:

- по одному: ввести значение и нажать Enter или «Добавить»;
- несколько сразу: через запятую в той же строке;
- «Списком…»: вставить много значений, по одному в строке.

Каналы и сообщества можно вставлять ссылками (`https://t.me/name`, `@name`, `vk.com/name`): приложение
само выделит имя. Повторы пропускаются, некорректные значения показываются под полем.

Ключевые слова — это быстрый предфильтр: запись идёт в оценку, если содержит хотя бы одно слово как часть
текста («разработ» найдёт «разработка» и «разработчик»). Пустой список пропускает всё.

**Сервисный ключ VK** бесплатный: dev.vk.com → Мои приложения → создать приложение → «Сервисный ключ
доступа». Вставьте его в настройках источника «VK-сообщества», он сохранится в Связке ключей.

Яндекс Карты, 2ГИС, поисковые системы, Kwork и Habr Freelance не подключены: бесплатно их использовать
нельзя или запрещено условиями. Причины показаны в разделе «Источники».

## Что ещё умеет приложение

- Три панели: навигация слева, таблица лидов в центре, контекстная панель справа. Кнопка правой панели —
  у правого края верхней панели (⌥⌘I).
- Разделы: Главная, Все лиды, Новые, Избранное, Источники, Журнал поиска, Архив, Исключённые.
- Таблица: сортировка, поиск по названию, описанию, контактам и заметкам, фильтры (тип, источник,
  регион, минимальная оценка), массовые действия, контекстное меню, экспорт.
- Панель лида: оценка и её причины, факты отдельно от предположений, контакты, заметка, история,
  черновик первого обращения (шаблон, отправка только вручную, массовой рассылки нет).
- Журнал поиска: каждый запуск, сколько найдено новых и обновлённых, ошибки по источникам.
- Исключения: домены (с поддоменами), телефоны, email, названия, импорт своей базы клиентов из CSV.
- Экспорт в CSV (с BOM для Excel) и JSON с выбором полей.
- Настройки (⌘,):
  - **Внешний вид:** тема (как в системе, светлая, тёмная), акцентный цвет, шрифты, масштаб 80–150%
    (⌘+ / ⌘− / ⌘0), плотность строк.
  - **Поиск:** автопроверка источников и работа в фоне: после закрытия окна приложение остаётся
    в строке меню и продолжает искать по расписанию (выключается там же).
  - **Учётная запись:** выход, запоминание входа, смена пароля.
  - **Данные:** расположение базы и перенос, ежедневные резервные копии, восстановление,
    копии в облачный диск (Dropbox, Google Диск, MEGA, Яндекс Диск, OneDrive, iCloud Drive, Box, pCloud)
    через папку бесплатного приложения провайдера. Рабочая база в облако не кладётся.
  - **Исключения** и **Обращения** (почта для отправки писем).
  - **Отчёты:** после вылета или зависания приложение предлагает отправить отчёт macOS
    (~/Library/Logs/DiagnosticReports). Текст показывается целиком и правится, домашняя папка и имя
    пользователя скрываются, затем в браузере открывается новое обращение в Issues, которое отправляете вы.
    Журнал ошибок хранится в ~/Library/Logs/LeadGenerator. Всё отключается. Меню «Справка» →
    «Сообщить о проблеме…».
  - **Обновления:** с выбранной частотой (от раза в час до раза в неделю, по умолчанию раз в сутки) проверяется последний релиз через публичный API GitHub (без токена).
    Если вышла новая версия, приложение покажет, что в ней нового, и по согласию скачает dmg, сверит
    SHA-256, заменит себя и перезапустится. Проверку можно выключить; вручную: «Customers» →
    «Проверить обновления…». Если папка с приложением недоступна для записи, откроется dmg для ручной установки.

## Установка

### Вариант 1. Установщик из релиза

1. Откройте [Releases](https://github.com/xop1tt/CLIENTS/releases/latest) и скачайте `Customers-vX.Y.Z-macOS.dmg`.
2. Откройте dmg и перетащите «Customers» на ярлык «Программы».
3. Первый запуск: правый клик по приложению → **Открыть** → **Открыть**. Сборка подписана локально
   (ad-hoc), без платного Apple Developer ID, поэтому macOS спрашивает подтверждение один раз.
4. Создайте учётную запись и нажмите «Найти лиды».

Начиная с 1.0.5 следующие версии ставятся из самого приложения (см. «Обновления»).
Контрольная сумма берётся из того же релиза: она защищает от повреждённой загрузки, но не заменяет подпись Apple.

Свежая сборка из любой ветки есть в **Actions → macOS app → Artifacts** (`Customers-macOS`, внутри dmg).

### Вариант 2. Сборка из исходников

Нужны Xcode 15+ или Command Line Tools (`xcode-select --install`).

```bash
cd macos
swift test                     # тесты: поиск, оценка, база, учётные записи
./scripts/build-app.sh         # соберёт build/Customers.app
./scripts/make-dmg.sh build/Customers.dmg   # по желанию: установщик
open "build/Customers.app"
```

Структура:

```
Sources/LeadGenCore/   модели, SQLite, база лидов, учётные записи, исключения, экспорт
Sources/LeadSearch/    источники, HTTP с лимитами и повторами, оценка, движок поиска
Sources/LeadGenerator/ приложение SwiftUI
Tests/                 тесты на фикстурах, без сети
```

Иконка: одна, тёмная. Исходник `Resources/AppIcon.svg`, растр `AppIcon-1024.png` строит `scripts/make-icon.py`,
при сборке из него получается `AppIcon.icns`. Подмены значка в Dock нет.

Для разработки: `open Package.swift` откроет проект в Xcode, схема `LeadGenerator`.

## Конфиденциальность

- Приложение обращается только к самим источникам (FL.ru и ваши RSS-ленты, t.me, api.vk.com,
  overpass-api.de) и к сайтам найденных организаций, один запрос на главную страницу.
- Никаких своих серверов, аналитики и GitHub: у локальной учётной записи лиды не покидают Mac.
  Облачная учётная запись дополнительно хранит их в вашем проекте Supabase, доступ — только у владельца (RLS).
- Ключ VK и запомненный вход лежат в Связке ключей, пароли — только в виде хэша.
